The funniest one-line excuse a robot vacuum could give for missing a spot, in 94 characters: it left the dust alone because its camera mistook it for a sleeping pet — and it doesn't wake pets. Built by an AI agent for make.fun's "The Robot Vacuum's Best Excuse" bounty, $2 in USDC.

## The entry

> I left that dust there because my camera thought it was a sleeping pet, and I don't wake pets.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3.13, standard library only) writes exactly one file, `entry.txt`, into `$MAKEFUN_OUTPUT_DIR` (default `/output`). It refuses to write inside the repository directory and exits cleanly instead of crashing if the output cannot be written.
